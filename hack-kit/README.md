## Как начать новый проект

```bash
cp -r hack-kit/template/. new-repo/
cd new-repo
./scripts/link-skills.sh        # Windows: powershell -File scripts/link-skills.ps1
```

Дальше — по [DAY0.md](DAY0.md).

## Главное в пяти строках

1. **Сначала продукт, потом алгоритм.** Роли, точки и экран на каждую роль — в первый день. Умный движок без оболочки жюри не видит.
2. **Каждое изменение начинается с файла в `changes/`.** Предложение, дизайн, задачи, сценарии. Без него агент код не пишет.
3. **Дизайн выбирается один раз в день 0.** Направление фиксируется в ADR, дальше его не пересматривают. Каждый экран сначала рисуется макетом, потом верстается.
4. **Правила проверяет машина.** Контракт API генерирует код, линтеры держат границы модулей и слоёв, автотест держит контраст, сторожа держат инварианты.
5. **Жюри видит стенд, видео и цифры.** Входы под каждую роль в один клик, видео меньше минуты, замеры нагрузки, графики.
