# e2e

Сквозные проверки демо-сценария на стенде. Сценарий — [docs/demo-script.md](../docs/demo-script.md).

## Запуск

Из папки `e2e/`:

```
npx playwright test -c playwright.config.ts
```

Конфиг — [playwright.config.ts](playwright.config.ts): один проект `firefox`, адрес стенда из `E2E_BASE_URL`, тесты в `tests/`.

## Правила

- Браузер — только Firefox.
- Переменные окружения (значения не печатать в чат, лог и коммит):
  - `E2E_BASE_URL` — адрес стенда;
  - `E2E_DEMO_TOKEN` — токен демо-доступа;
  - `E2E_MARKETER_PASSWORD`, `E2E_ANALYST_PASSWORD` — пароли демо-учёток `marketer` и `analyst` (`demo.spec.ts`).
- Перед каждым прогоном сбрось стенд к начальному состоянию, иначе сценарий может упасть на данных прошлого прогона.
- Чужие стенды — только чтение.

## Кто меняет `e2e/`

Только люди. Агент правку предлагает, слияние — после явного «да» человека. Правка, меняющая сторожей, содержит строку `INVARIANT-CHANGE`.

## Данные стенда

Суммы в `demo.spec.ts` (3 879,73 €, 3 459,27 €) верны для сида без `SEED_STAND` (по умолчанию `false`). При `SEED_STAND=true` `reset` возвращает 16 аккаунтов и 4 604,82 €, шаг 1 упадёт.
