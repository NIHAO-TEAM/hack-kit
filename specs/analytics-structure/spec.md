# analytics-structure

### Requirement: поведение не меняется

#### Scenario: пути аналитики

- WHEN клиент вызывает любой путь `analytics` до и после изменения
- THEN ответы одинаковы
- Тест: `internal/analytics` (`go test`), обработчики-заглушки отвечают 501

### Requirement: потеря в разрезе причин

Сводка SHALL отдавать `lossByFeature`: по каждой причине идентификатор признака, ожидаемую потерю в центах, число клиентов и долю; сумма по причинам равна ожидаемой потере до цента.

#### Scenario: набор организаторов

- WHEN запрошена сводка на данных организаторов
- THEN сумма `lossCents` по причинам равна 359 907 центов (3 599,07 €), список упорядочен по убыванию потери
- Тест: `internal/risk` `TestGolden` (golden-тест распределения по причинам), `internal/analytics` `TestSummaryLossByFeature`

### Requirement: блок «Где теряем деньги»

«Сводка» SHALL показывать потерю по причинам полосами с суммой в € и долей и подписью, что распределение идёт по вкладу признаков, а не доказывает причинность.

#### Scenario: блок на сводке

- WHEN маркетолог открывает «Сводку»
- THEN виден блок «Где теряем деньги» с причинами в порядке убывания потери
- Тест: `src/app/summary.test.tsx`
