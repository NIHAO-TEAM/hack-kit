# web-shell

### Requirement: вход в панель

Панель SHALL пускать только вошедшего пользователя.

#### Scenario: открыть панель без входа

- WHEN браузер без сессии открывает любую страницу панели
- THEN показывается экран входа; после верного логина и пароля открывается стартовая страница роли
- Тест: router.test.tsx › охрана маршрутов › без сессии любой раздел ведёт на экран входа; вход и выход › верный пароль открывает стартовую страницу маркетолога

#### Scenario: неверный пароль

- WHEN пользователь вводит неверный пароль
- THEN под формой текст «Неверный логин или пароль», поля сохраняют логин
- Тест: router.test.tsx › вход и выход › неверный пароль: текст ошибки, логин сохранён

#### Scenario: слишком много попыток

- WHEN сервер ответил `429`
- THEN текст объясняет, через сколько минут можно повторить
- Тест: router.test.tsx › вход и выход › 429: текст говорит, через сколько минут повторить

### Requirement: стартовая страница роли

После входа система SHALL открывать рабочую страницу роли.

#### Scenario: вход жюри

- WHEN `jury` входит по паролю
- THEN открыт экран «Очередь»
- Тест: router.test.tsx › вход и выход › вход жюри открывает очередь; rights.test.ts › homePath › пользователь (маркетолог, аналитик) и жюри начинают с очереди, администратор с модели

### Requirement: навигация по роли

#### Scenario: пользователь

- WHEN входит `marketer` или `analyst`; в интерфейсе роль подписана «пользователь»
- THEN в навигации «Очередь», «Сводка», «Модель», «Источник», «О модели»
- Тест: router.test.tsx › охрана маршрутов › в навигации пользователя (маркетолога) есть «Модель» и «Источник»; rights.test.ts › can

#### Scenario: выход

- WHEN пользователь нажимает «Выйти»
- THEN сессия завершена, показывается экран входа, кнопка «назад» не возвращает в панель
- Тест: router.test.tsx › вход и выход › выход возвращает на экран входа

### Requirement: мониторинг по ссылке

Интерфейс SHALL давать ссылку на Grafana ролям, которые видят источник данных.

#### Scenario: жюри открывает мониторинг

- WHEN `jury` или пользователь нажимает «Мониторинг» в шапке
- THEN в новой вкладке открывается `/grafana/`
- Тест: router.test.tsx › охрана маршрутов › пользователь и жюри видят ссылку «Мониторинг» на /grafana/ в новой вкладке

### Requirement: работа без бэкенда

#### Scenario: моки

- WHEN фронт запущен в режиме моков
- THEN вход и навигация работают на данных организаторов без запущенного API
- Тест: ручная проверка: `pnpm dev:mock`, вход `marketer`/`demo`
