# e2e

### Requirement: проверка экранов 100k не краснеет от отмены загрузки браузером

Проверка `Deploy UI 100k` SHALL не считать ошибкой экрана загрузку шрифта, отменённую браузером при переходе (`NS_BINDING_ABORTED`), и SHALL считать ошибкой любую другую ошибку консоли.

#### Scenario: переход отменил загрузку шрифта

- WHEN Firefox пишет `downloadable font: download failed ... status=2152398850` при переходе между экранами
- THEN проверка «ошибки консоли» проходит, в журнале шагов есть строка о прерванной загрузке
- Тест: `e2e/tests/ui-100k.spec.ts`

#### Scenario: шрифт не найден

- WHEN шрифт отвечает 404 или не разбирается
- THEN проверка «ошибки консоли» падает
- Тест: опыт в «Найдено по ходу»
