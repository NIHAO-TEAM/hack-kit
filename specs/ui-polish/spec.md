# ui-polish

### Requirement: без сырых мест

#### Scenario: любой экран

- WHEN открыт любой экран в любой теме
- THEN нет технических id вместо названий, непереведённых ключей, обрезанных текстов и пустых экранов без пояснения; один h1; нет горизонтальной прокрутки на 390 и 820; axe без serious/critical
- Тест: frontend/src/app/customer-screen.test.tsx: «раскрытая услуга не выдаёт признаки клиента за свои» (имя кнопки услуги без id); остальное — проверка axe по скиллу frontend-design-review

### Requirement: доступность проверяется автотестом

Экраны ролей SHALL проходить axe (WCAG 2 AA) без нарушений `serious` и `critical` в обеих темах.

#### Scenario: после выката

- WHEN выкат на прод прошёл и дымовая проверка зелёная
- THEN `deploy-a11y.yml` проходит экраны `jury` в тёмной и светлой теме на 1440 и 390 без нарушений `serious` / `critical`
- Тест: e2e/tests/a11y.spec.ts: «axe: 1440px, тема dark» и три соседних

#### Scenario: нарушение

- WHEN на экране текст не проходит контраст AA
- THEN прогон красный, в выводе экран, тема, правило и элемент
- Тест: e2e/tests/a11y.spec.ts: сообщение `нарушения axe:` в каждом из четырёх тестов
