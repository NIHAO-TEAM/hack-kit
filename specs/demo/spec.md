# demo


## Requirement: демо воспроизводимо

### Scenario: три раза подряд

- WHEN e2e демо запускается три раза подряд после сброса стенда
- THEN все три прогона зелёные

- тест: e2e/tests/demo.spec.ts

## Requirement: каждый шаг живого демо проверяется прогоном

Каждый шаг живого демо в `docs/demo-script.md` SHALL иметь шаг в `e2e/tests/demo.spec.ts`, проверяющий то, что видит жюри.

### Scenario: полный сценарий защиты

- WHEN `Demo e2e` проходит на чистом стенде
- THEN пройдены: найти клиента, объяснить причины и деньги, изменить коэффициент и данные, увидеть обновление без перезагрузки, поток событий с согласованностью 0 центов

- тест: e2e/tests/demo.spec.ts (`демо: очередь → карточка → потеря по причинам → вес → устойчивость → автопродление → поток событий → /metrics`)

## Requirement: демо-сценарий проходит в Firefox без обрывов навигации

Демо-сценарий SHALL ждать готовности страницы перед следующим переходом и проходить на чистом стенде три раза подряд без сбоев.

### Scenario: переход на «Сводку»

- WHEN сценарий открывает `/queue`, затем `/summary`
- THEN заголовок «Где теряем деньги» виден, ошибок навигации нет

- тест: e2e/tests/demo.spec.ts (шаг «Сводка: где теряем деньги»)
