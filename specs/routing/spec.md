# routing

### Requirement: неизвестный путь

Система SHALL отвечать `404` на путь, которого нет среди маршрутов, и добавлять `X-Request-Id`.

#### Scenario: путь не существует

- WHEN клиент отправляет `GET /nope`
- THEN ответ `404`, в ответе есть `X-Request-Id`
- Тест: `TestNotFound/неизвестный_путь`, `TestNotFound/подпуть_известного_маршрута`
