# Сессии с экспертами

Расписание и подготовка. Ведёт пахан (`.github/agents/lead.md`, раздел «Сессии с экспертами»), время и людей сообщает человек.

## Расписание

| Когда (дата, время, пояс) | Эксперт | Тема | Длительность | Файл вопросов | Статус |
|---|---|---|---|---|---|
| 2026-10-23 22:22–22:31 MSK | эксперт aéza | что решает при равном качестве, совмещение кейсов | переписка | [2026-10-23-aeza-chat.md](2026-10-23-aeza-chat.md) | проведена |

## Порядок

1. Человек называет время, эксперта и тему. Пахан вносит строку.
2. Пахан готовит файл вопросов по `_template.md` не позже чем за 2 часа до начала. Человек правит и утверждает.
3. На сессии человек (или кто-то из команды) записывает ответы в раздел «Ответы» файла: слова эксперта, без своих выводов.
4. После сессии пахан разбирает ответы, предлагает правки `docs/plan.md` / `docs/scale.md` и новые изменения, пишет сводку на пять строк. Решает человек.

## Правила

- Слова эксперта не решение. Решение записывает человек в разделе «Решения по итогам».
- Вопросы закрытые или с вариантами, не больше семи; в каждой сессии спрашиваем про критерии жюри и что эксперт хотел бы увидеть на демо.
- Эксперт не обязан знать нашу кухню: вопрос формулируется так, чтобы отвечать можно было, не читая репозиторий.
- Файл сессии не удаляется; поправки в ответах датируются.
