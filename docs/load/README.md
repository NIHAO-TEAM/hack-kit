# Замеры нагрузки

Образец — «Остаток» (2 место UMIRHack 2026): таблица сценариев с RPS, p95 и ошибками, плюс честная оговорка о железе.

## Сценарии

| Сценарий | Что доказывает |
|---|---|
| Чтение главного списка, кэш вкл/выкл | Быстро отвечаем на самый частый запрос |
| N одновременных записей на M штук остатка | Ровно M успешных, остальные — понятный отказ, в минус не ушло |
| Смешанная нагрузка 60 с | 0 ошибок 5xx, p95 |

Плюс тест свойств в CI (как `TestStockStaysConsistentUnderLoad` у Goden): после нагрузки остаток равен пересчёту с нуля. Он проверяет свойство, а не число.

## Результаты

Файл на прогон: `YYYY-MM-DD-<сценарий>.md` — железо, команда запуска, таблица, вывод одной фразой.

> Замер на <железо>. Это порядок величин, а не обещание для боевого сервера.
