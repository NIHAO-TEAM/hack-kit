## Механика процесса (что уже автоматизировано)

| Что | Где | Как |
|---|---|---|
| Раздача черновиков | `assign.yml`, `assign.sh` | этап `утверждён` в `docs/plan.md` + строка `зависит от` в `proposal.md`; строки этапов ищутся только в разделе «Разбивка на этапы» |
| Конфликт с `main` | `conflicts.yml`, `conflicts.sh` | после каждого push в `main` будит исполнителя PR в `CONFLICTING` (`[guard] … (конфликт с main @sha)`) |
| Умершая сессия | `watchdog.yml`, `watchdog.sh` | цепочка раз в ~15 мин; итог без ответа 40 мин, черновик без жизни 45 мин, метка без `[start]` 30 мин, **снятый `needs-human` — через 2 мин** |
| `needs-human` | исполнитель | только: нужны секреты/доступы; `tests/invariants/` или ослабление гейта; иначе нарушается ADR или приёмка. Причина устранена — снимаешь метку с `[lead]`-комментарием, сторож разбудит |
| Права исполнителя | `executor.md` | можно `deploy/`, `e2e/`, новые `.github/workflows/deploy*.yml` с причиной в `proposal.md`; нельзя сторожей, инструкции агентов, существующие гейты |
