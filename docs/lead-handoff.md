- В jq-выражениях `gh --jq` нельзя `\[` — используй `^.(start|fix)` вместо `^\[(start|fix)`.
- Классификатор auto-режима может отклонить запись в секреты и правку прав агентов — не обходить, спросить человека.
- Bash-heredoc с длинным русским текстом и `python - <<EOF` с кириллицей ломаются: файлы черновиков пиши через Write в scratchpad, правки — через Edit. Скрипт открытия черновиков — `scratchpad/open-drafts.sh` (worktree на ветку, коммит папки, `gh pr create --draft --label change`); после сессии его нет, логика простая.

## Проверка доски одной командой

```bash
GH="/c/Program Files/GitHub CLI/gh.exe"
"$GH" run list --workflow ci.yml --branch main -L 1 --json conclusion --jq '.[0].conclusion'
"$GH" pr list --state open --limit 100 --json number,title,isDraft,mergeable,labels \
  --jq '.[]|"#\(.number) \(.title) \(.mergeable) [\([.labels[].name]|map(select(startswith("go:") or .=="needs-human" or startswith("round")))|join(","))]\(if .isDraft then " draft" else "" end)"'
```
