# Токены темы (ADR-0003)

Источник значений — `frontend/src/shared/ui/theme/tokens.ts`; контраст проверяет `contrast.test.ts` (текст ≥ 4,5 : 1, элементы ≥ 3 : 1). Имена по роли, не по оттенку.

| Токен | Тёмная | Светлая | Роль |
|---|---|---|---|
| `bg` | `#000000` | `#f4f4f4` | фон страницы (цвета брендбука) |
| `surface` | `#0f1114` | `#ffffff` | карточки, таблицы |
| `primary` | `#4cc6f1` | `#08708f` | заливка главной кнопки |
| `on-primary` | `#000000` | `#ffffff` | текст на кнопке (белый на `#4cc6f1` не проходит AA) |
| `primary-hover` | `#72d4f5` | `#06566f` | наведение |
| `primary-fg` | `#4cc6f1` | `#08708f` | ссылки, активная навигация |
| `focus-ring` | `#4cc6f1` | `#08708f` | фокус |
| `changed-tint` | `#10303c` | `#eaf7fc` | подсветка изменившейся строки |
| `warn-solid` / `warn-fg` | `#e97c35` | `#c2410c` | окно закрывается (оранжевый брендбука; на светлом темнее ради AA) |
| `critical-*` | `#ff6b6b` | `#b91c1c` | меньше 24 ч (без изменений) |
| `effect-*` | `#4ade80` | `#117a37` | эффект действия: зелёный вместо бирюзового, чтобы не сливаться с акцентом |
| `lost-*` | серый | серый | потеряно (без изменений) |

Шрифты: Exo 2 (400/600/700) — заголовки и текст, Inter (400/500/600) — подписи; цифры во всём интерфейсе — Inter с `tabular-nums` (`@font-face Digits`, `unicode-range` U+0030–0039).
