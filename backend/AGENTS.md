# AGENTS.md — backend

Дополняет корневой [AGENTS.md](../AGENTS.md). Стек по умолчанию — Go + PostgreSQL (наш опыт SwapOwl и выбор Goden). Другой стек — отдельный ADR.

## Стек

| Что | Выбор |
|---|---|
| Язык | Go (версия фиксируется в `go.mod` и во всех `Dockerfile` одинаково) |
| HTTP и контракт | `api/openapi.yaml` → генератор сервера (ogen или oapi-codegen, решается в ADR-0005) |
| SQL | sqlc: запросы в `queries.sql` модуля, код в подпакете `db/` |
| Миграции | goose или golang-migrate, по файлу на изменение схемы |
| База | PostgreSQL; в тестах — настоящая (локальный кластер или testcontainers), моков базы нет |
| Реальное время | SSE |
| Метрики | Prometheus (`/metrics`), дашборд Grafana в `deploy/` |
| Линтер | golangci-lint с depguard |

## Команды

```bash
make generate     # код из openapi.yaml и sqlc; CI проверяет, что диффа нет
make check        # gofmt, go vet, golangci-lint, go test -race ./...
make test-int     # интеграционные тесты (тег integration), нужен PostgreSQL
make load         # нагрузочный прогон, результаты в docs/load/
```

## Модульный монолит

Модуль — один пакет `internal/<модуль>/`:

- `<агрегат>.go` — сущность и **чистые функции решений** без ввода-вывода и без `time.Now()`;
- `service.go` — команды: загрузить состояние, принять решение, записать;
- `queries.sql` + `db/` — SQL модуля;
- `http.go` — обработчики своей части сгенерированного API;
- `events.go` — события модуля, если модуль их публикует.

Границы:

- Модуль обращается к другому только через его экспортируемые типы и интерфейсы.
- Модуль не читает и не меняет таблицы другого модуля.
- `internal/platform/...` (часы, БД, HTTP-обвязка, метрики) не импортирует доменные модули.
- Циклы запрещены, общий тип — в модуль-владелец.

Границы проверяет depguard (`.golangci.yml`). Нарушение исправляется в коде, а не исключением в конфиге.

## Правила кода

- Время приходит через `clock.Clock`. `time.Now()` в доменном коде запрещён.
- Количества — целыми в базовых единицах (г, мл, шт). Никаких float в остатках, ценах и рецептах.
- Запись с повтором — заголовок `Idempotency-Key`; повтор возвращает тот же результат, а не дубль.
- Ошибки — `application/problem+json` (RFC 9457): `type`, `title`, `status`, `detail`, `correlation_id`, `errors[]` для полей.
- `X-Correlation-Id` проходит в логи и события.
- Права проверяются на сервере по назначению на точке. Данные одной точки не видны в другой — тест на каждую операцию.
- Пагинация — `limit` (1..200), `offset`, ответ `{items, total}`.

## Контракт

1. Сначала меняется `api/openapi.yaml` (отдельное изменение с пометкой «контракт»).
2. `make generate` — код сервера; фронт делает `pnpm api:types`.
3. Затем реализация.

Сгенерированный код коммитится и руками не правится. Несовместимое изменение согласуется с фронтом в `proposal.md`.

## Тесты

- Доменные функции — табличные unit-тесты без базы.
- Время — `testing/synctest` и фейковые часы.
- `apitest.New(t)` поднимает весь API тем же конструктором, что `cmd/api`, на отдельной базе и возвращает сгенерированный клиент. Тесты эндпоинтов ходят через клиент.
- Хелперы ролей: `s.Staff(t, "cook")` — клиент сотрудника с правами роли на точке теста; `s.OtherPoint(t)` — чужая точка для проверки изоляции.
- Метрики проверяются в тестах: `s.Metric(t, "app_commands_total", "command", "PlaceOrder")`.
- Формат события — контракт: эталон JSON в `testdata/`, меняется только вместе с согласованным изменением.
- **Сторожа `tests/invariants/`** — меняют только люди. Упал — ошибка в коде.
- **Тест свойств под нагрузкой:** N параллельных команд на M единиц остатка → ровно M успешных, остаток равен пересчёту с нуля, ничего не ушло в минус.
- Интеграционные тесты — `*_integration_test.go` с `//go:build integration`.
