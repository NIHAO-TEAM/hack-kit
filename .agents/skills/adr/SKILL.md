# ADR

Файл `docs/adr/NNNN-<имя>.md`, номер — следующий по порядку. Шаблон — `docs/adr/0000-template.md`.

## Когда нужен

- Выбор, который дорого переиграть: хранилище, событийная модель, авторизация, роли и точки, стек фронта, направление дизайна.
- Правило, которое будет проверять машина: граница модулей, запрет на импорт, токены.
- Отмена прежнего ADR — новый ADR со ссылкой «Заменяет ADR-NNNN», у старого статус «заменён».

## Как писать

- **Контекст** — факты и ограничения, не мнения. Что из кейса, что из кода, что из сроков.
- **Решение** — одно, коротко, в повелительном наклонении: «Состояние меняется только событиями».
- **Последствия** — что становится проще, что сложнее, какие гейты это проверяют. Если гейта нет — так и написать.
- **Отброшено** — варианты и по одной строке почему.

Статус ставит человек: `предложено → принято → заменено`.
