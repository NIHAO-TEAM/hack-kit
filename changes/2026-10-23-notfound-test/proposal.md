# 404 на неизвестный путь

## Зачем

Тест I (23.10): проверка работы без людей в NIHAO-TEAM — автоназначение по этапу «А» наименее загруженному исполнителю, исполнители на разных аккаунтах, ревьюер valotr0n, слияние агентом. Поведение полезно зафиксировать: клиент должен получать 404 и X-Request-Id для поиска в логах.

## Что меняется

- Тест: `GET /nope` и `GET /healthz/extra` → `404`, в ответе есть `X-Request-Id`. Код сервера не меняется.

Вне изменения:
- Код обработчиков, контракт, другие тесты.

- frontend: нет
- контракт `api/openapi.yaml`: нет
