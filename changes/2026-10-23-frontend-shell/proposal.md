# Оболочка фронта: стек, типы из контракта, моки, вход и навигация по ролям

## Зачем

Критерий жюри — «качество интерфейса»; требование — «Веб-панель», «Аутентификация» (`docs/case.md`). Экраны этапа 4 (очередь, карточка, модель) верстаются в готовую оболочку параллельно бэкенду, на моках из того же контракта (`frontend/AGENTS.md`). Сейчас во `frontend/` нет приложения — только `package.json` с `node --test`.

## Что меняется

- Приложение по стеку `frontend/AGENTS.md`: React + TypeScript strict + Vite, pnpm, TanStack Router (маршруты файлами) и Query, Mantine, `openapi-typescript` + `openapi-fetch`, MSW, ESLint, Prettier, Stylelint, steiger, Vitest. Версии фиксируются точно.
- `pnpm api:types` генерирует типы из `api/openapi.yaml`; `pnpm dev:mock` работает без бэкенда на моках из спеки (данные моков — набор организаторов).
- Экран входа по логину и паролю: ошибки по-человечески, после входа — на стартовую страницу роли.
- Оболочка: навигация по ролям (маркетолог — «Очередь», «Сводка»; аналитик — ещё «Модель», «Источник»), имя пользователя, выход; маршруты-заглушки с пятью состояниями (загрузка, пусто, ошибка, нет связи, нет прав).
- Охрана маршрутов: без сессии — на вход; раздел без права — экран «Недостаточно прав».
- `pnpm check` (типы без диффа, typecheck, линтеры, тесты, сборка) и `pnpm build` в `frontend/dist`.

Вне изменения:
- Направление дизайна, токены, тёмная тема по ADR-0002 — `design-tokens` (этап 3). Здесь — стандартная тема Mantine, светлая и тёмная из коробки, без своих цветов.
- Экраны очереди, карточки, модели, источника — этапы 4–5.
- SSE и живое обновление — `live-updates` (этап 4).
- Встраивание в Go-бинарь и Dockerfile — `compose-stand`.

## Затронутые части

- backend: нет
- frontend: `app/` (провайдеры, роутер, оболочка), `pages/login`, `pages/*` заглушки, `entities/session`, `shared/api`, `shared/ui` (пять состояний)
- контракт `api/openapi.yaml`: нет (только читает)
- защищённые пути: нет

## Связанные решения

- ADR: 0001 (роли); 0002 — ещё не принят, поэтому без своей вёрстки
- Макет: не нужен — экран входа и оболочка на стандартных компонентах Mantine без своей вёрстки; переодеваются в `design-tokens` после ADR-0002
