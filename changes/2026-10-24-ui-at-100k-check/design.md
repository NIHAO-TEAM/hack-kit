# Дизайн: интерфейс на 100k

## Подход

1. Стенд — как `deploy-load.yml` (генерация 100k, загрузка снимка), затем Playwright из `e2e/`.
2. Время экрана: от `goto` до появления главного элемента (таблица, карточка, график) — `performance.now()` в тесте; плюс время ответов API из `page.on('response')`.
3. CSV: `page.waitForEvent('download')`, размер файла и число строк; память процесса — `process_resident_memory_bytes` до и после.
4. Нарушение цели — тест красный с таблицей.

## Допущения

- [ПРЕДПОЛОЖЕНО] Цели времени — для 4 vCPU раннера; числа пишем как есть.

## Риски

- Долгая генерация 100k в раннере — кэшировать файл между шагами.
