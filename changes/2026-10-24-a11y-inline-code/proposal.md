# Доступность: последнее нарушение axe на «О модели»

## Зачем

После `a11y-pagination-labels` (#121) `deploy-a11y.yml` на 51be46a всё ещё красный одним нарушением: «о модели · dark · 390px · scrollable-region-focusable · code». Блок формулы (`<Code block>`, это `<pre>`) уже получил `tabIndex`; селектор `code` указывает на другой элемент — [ПРЕДПОЛОЖЕНО] строчный `<Code>tools/oracle</Code>` (`frontend/src/pages/about-model/ui/AboutModelPage.tsx:187`), у которого стиль Mantine даёт `overflow: auto`, и на узком экране содержимое прокручивается на доли пикселя. Шкала 5.9: контраст и доступность проверены автотестом — нужен зелёный прогон.

## Что меняется

- Найден фактический элемент нарушения (локальный прогон `a11y.spec.ts` / axe в jsdom или по скриншоту артефакта `a11y-screenshots`).
- Если это строчный `Code` — ему `overflow: visible` (или обычный моноширинный текст): прокрутки у строчного кода быть не должно. Если другой элемент — та же правка по месту.
- `deploy-a11y.yml` на `main` после слияния зелёный — тогда README может честно говорить «доступность проверяется после каждого выката».

Вне изменения:
- Вид страницы — без изменений.
