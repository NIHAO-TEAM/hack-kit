# deploy: прод на k3s со спутниками

## Требование: прод отдаёт все заявленные службы через один вход

WHEN открыт `https://<домен>/grafana/`
THEN показывается экран входа Grafana, а не фронт приложения

WHEN запрошен `https://<домен>/sso/realms/churn/.well-known/openid-configuration`
THEN ответ — JSON Keycloak

WHEN нажата «Войти через SSO» на проде
THEN браузер уходит в Keycloak (ответ `/api/v1/auth/oidc/login` — редирект, не 501)

WHEN к адресу прода обращаются напрямую на порты 3000, 8080, 9090
THEN соединение не устанавливается

## Требование: смоук прода зелёный

WHEN выкат из `main` завершился успешно
THEN `deploy-smoke.yml` проходит все шаги, включая вход `jury` и очередь
