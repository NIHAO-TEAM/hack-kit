# «Что если» прямо в очереди: ползунок веса и предпросмотр

## Зачем

Защита, шаг 3 — самый наглядный момент; Альтернативщик дебатов: «живой “что если” на одном экране» (`docs/decision/r1_C.md`).

## Что меняется

- Кнопка «Что если» над очередью открывает панель: выбор признака, ползунок веса; по `dryRun` — «сменят уровень N клиентов, потеря ±X €» и список клиентов, которые сменят уровень.
- «Применить» доступно аналитику (сохраняет настройки), маркетологу — только просмотр.

Вне изменения:
- Перестройка самой таблицы до сохранения — нет: таблица обновится после «Применить» через SSE.

- frontend: `widgets/whatif-panel`, кнопка на `pages/queue`
- контракт `api/openapi.yaml`: добавления в этом PR, если нужны (без поломки)
- защищённые пути: нет
- зависит от: `queue-screen`, `settings-api`
