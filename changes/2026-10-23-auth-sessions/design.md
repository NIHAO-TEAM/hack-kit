# Дизайн: вход, сессии, права

## Подход

- **Пароли:** argon2id (`golang.org/x/crypto/argon2`), параметры в константах, сравнение за постоянное время.
- **Сессия:** 32 случайных байта, в базе — SHA-256 токена (`sessions.token_hash`), срок 12 ч; `csrf_token` — отдельные 32 байта, отдаётся в теле `login` и в `GET /auth/me`.
- **Транспорт:** один и тот же токен — в cookie `session` и в теле ответа `login` (`{token, csrfToken, user}`); middleware принимает `Authorization: Bearer <token>` или cookie. CSRF проверяется только когда сессия пришла из cookie и метод не GET/HEAD/OPTIONS.
- **Лимит попыток:** 5 неудач за 5 минут на пару (логин, IP); IP — из `X-Forwarded-For` только если `TRUSTED_PROXY=true`; ответ `429` `problem+json` с `Retry-After`.
- **Учётки из окружения:** при старте upsert по логину; пароль меняется, если изменилась переменная. Администратор из `.env` помечен `managed_by_env` и не редактируется через API.
- **Права** — функция `can(role, operation)` по таблице, middleware на каждую операцию сгенерированного сервера (по `operationId`):

| Операция | marketer | analyst | jury | admin |
|---|---|---|---|---|
| `auth/*`, `customers*`, `analytics/*`, `events`, `source/status`, `model/settings` GET | да | да | да | да |
| `model/settings` PATCH (и `dryRun`) | нет | да | да | да |
| `source/snapshot` PUT, `source/services|accounts` PATCH, `source/emulator/*` | нет | да | да | да |
| `metrics` | да | да | да | да |

- **Сервисный токен источника** (`SOURCE_TOKEN`) даёт только `PUT /source/snapshot`; токен сборщика (`METRICS_TOKEN`) — только `/metrics`. Ни один не открывает панель.
- Логи: логин пишется, пароль, токен и cookie — никогда.

## Отброшенные варианты

| Вариант | Почему нет |
|---|---|
| Обязательный TOTP для аналитика | ломает проверку жюри по паролю (P0 дебатов) |
| JWT без хранения | нельзя честно завершить сессию в `logout` |
| Только cookie | Swagger «Try it out» и curl жюри без CSRF-заголовка получат 403 |

## Допущения

- [ПРЕДПОЛОЖЕНО] Срок сессии 12 ч — с запасом на демо.
- [ПРЕДПОЛОЖЕНО] Роль `jury` = аналитик по правам; отдельна, чтобы её можно было отключить после хакатона.

## Риски

- Лимит попыток за прокси без `X-Forwarded-For` заблокирует всех сразу — поэтому ключ «логин + IP», а не только IP.
