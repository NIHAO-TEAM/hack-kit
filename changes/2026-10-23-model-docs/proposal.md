# Описание модели и архитектуры для жюри + экран «О модели»

## Зачем

Приёмка: «краткое описание модели и архитектуры, способ добавления нового признака»; «Выбор необходимо кратко объяснить жюри» (`docs/case.md`). Критерий — «обоснованность модели».

## Что меняется

- `docs/model.md` — одна страница: признаки и смысл каждого веса, формула, уровни, деньги, допущения (подтверждённые экспертом — с пометкой), чувствительность «вес ±0,1 → потеря ±X €».
- `docs/architecture.md` — схема модулей и потоков (снимок → пересчёт → API/SSE/метрики), деплой, безопасность, как встать в контур aéza (`values.yaml`).
- README: раздел «Модель и архитектура» со ссылками; «Как добавить признак» — ссылка на PR `feature-bonus-locked`; раздел «Дополнительно» — перечень функций сверх обязательных.
- Экран «О модели» — то же, что `docs/model.md`, с числами из `GET /model/settings`.

Вне изменения:
- Слайды — этап 8.

## Затронутые части

- backend: нет
- frontend: `pages/about-model`, маршрут `_app.about.tsx`
- контракт `api/openapi.yaml`: добавления в этом PR, если нужны (без поломки)
- защищённые пути: нет
- зависит от: `design-tokens`, `money-actions`, `risk-features`
