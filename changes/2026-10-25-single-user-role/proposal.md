# Маркетолог и аналитик — один пользователь

## Зачем

Эксперт aéza 25.10 10:38: «сущность маркетолог и аналитик — это один и тот же человек, в целом просто “юзер”». Сейчас (проверено по коду) у них разные права: маркетолог не видит «Модель» и «Источник» и не меняет веса (`backend/internal/auth/permissions.go`, `accessStaff`; `frontend/src/entities/session/model/labels.ts`), аналитик не работает с задачами клиента (`accessWork`). На демо приходится входить двумя учётками. Шкала: «Полезность», «UX».

## Что меняется

- Роль `marketer` получает все права аналитика: «Модель» (просмотр и правка весов), «Источник», журнал. Права работы с клиентом у неё остаются. Итог: один вход — весь продукт.
- Роль `analyst` получает права работы с клиентом (`accessWork`), то есть тоже всё — учётка остаётся для совместимости (сид, Keycloak, тесты), по сути синоним.
- В интерфейсе роль подписана «пользователь» (вместо «маркетолог» / «аналитик»); тексты «доступно аналитику» на экране «Недостаточно прав» — «пользователю».
- `jury` и `admin` не меняются.

Вне изменения:
- Удаление роли `analyst` из контракта (`enum Role`) и Keycloak — ломающая правка контракта, не до стоп-кодинга.
- Новые права и роли.

## Затронутые части

- backend: `internal/auth` (матрица прав), тесты прав
- frontend: `entities/session` (права ролей, подписи), тексты «Недостаточно прав», меню
- контракт `api/openapi.yaml`: нет (enum Role без изменений; описание ролей в тексте — по желанию исполнителя, не ломающее)
- защищённые пути: `tests/invariants/` — **только если** там закреплено «маркетолог не меняет модель»; такой сторож меняют люди (`INVARIANT-CHANGE`), исполнитель ставит `needs-human`
- зависит от: нет

## Связанные решения

- **ADR-0001 меняется**: «Роли: маркетолог (очередь и карточка клиента), аналитик (модель и источник данных)» → «пользователь (всё, кроме администрирования), `jury`, администратор». Решение владельца по словам эксперта 25.10 — нужна строка «Дополнение 25.10» в ADR-0001 (задача 3.1). `AGENTS.md` (корень, раздел «Проект») описывает роли — правит пахан по «да» человека, не исполнитель.
- Макет: нет, экраны не меняются, меняется доступ.
