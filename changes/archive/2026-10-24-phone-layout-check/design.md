# Дизайн: проверка вёрстки на телефоне и планшете

## Подход

1. Вход и обход экранов — как в `a11y.spec.ts` (общий помощник, если он там есть; иначе копия входа).
2. Горизонтальная прокрутка: `document.documentElement.scrollWidth <= window.innerWidth + 1`.
3. Цели касания: список селекторов по ролям (`getByRole('button', { name: … })`), `boundingBox()` ≥ 44 × 44; вывод — экран, элемент, размер.
4. Ожидание данных — по роли таблицы/заголовку, не `networkidle` (SSE).

## Допущения

- [ПРЕДПОЛОЖЕНО] Тест только читает прод: «Взять в работу» не нажимается, проверяется только размер.
- [ПРЕДПОЛОЖЕНО] Иконки-кнопки в шапке (тема, мониторинг, выход) — тоже цели касания, 44 px на 820.

## Риски

- Новый workflow — защищённый путь; существующие workflow и гейты не меняются.
