# Grafana на проде: дашборд за входом

## Зачем

Эксперт: инфраструктура — плюс, «если в проде доступно нам и секьюрно». Шкала, «Продукт и стабильность» 9: «Мониторинг открывается по ссылке, на графиках видно работу демо».

## Что меняется

- Grafana по пути `/grafana`, анонимный доступ выключен, пароль администратора — из `.env` прода; учётка жюри — viewer.
- Дашборд из провижининга (`deploy/grafana/`): клиенты по уровням, ожидаемая потеря, время пересчёта, возраст снимка, ошибки качества данных, HTTP.

Вне изменения:
- Алерты в мессенджер — нет.

## Затронутые части

- backend: нет
- frontend: нет
- контракт `api/openapi.yaml`: добавления в этом PR, если нужны (без поломки)
- защищённые пути: да — `deploy/`, разрешено
- зависит от: `prometheus-prod`
