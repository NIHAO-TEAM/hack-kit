# Карточка клиента: причины риска по услугам вместо формулы

## Зачем

Эксперт aéza 25.10: «вычисления в UI не требуются». На уточнение (11:05): «Да, речь о ней [формуле], в целом её лучше убрать или добавить именно Причины… маркетолог-аналитик скорее на глазок анализирует, поэтому ему лучше показать причины риска, а не формулу расчёта»; «По конкретным услугам например. То есть какая услуга какой вес даёт, что именно плохого. Есть признаки, а эти признаки вытекают из причин».

Проверено по коду: в карточке клиента блок «Признаки риска клиента» — таблица «признак / значение / вес / вклад» и строка `P = 1 − (1 − 0,65·1) · … = 0,9` (`pages/customer/ui/FeaturesCard.tsx`, `formulaText`); та же строка у риска услуги (`ServiceRiskPanel.tsx`, `data-testid="service-formula"`). Данные для причин по услугам уже есть в ответе `GET /customers/{id}`: `serviceRisks[]` — `lossCents` и `features[]` с `reason` у каждой услуги. Шкала: «Полезность для маркетолога», «Объяснимость», «UX».

## Что меняется

- Вместо блока «Признаки риска клиента» — блок **«Причины риска»**, сгруппированный **по услугам**:
  - услуги с потерей > 0 — по убыванию потери; у каждой — название услуги, сумма под угрозой в € и полоса доли в потере клиента («какой вес даёт услуга»);
  - под услугой — что именно плохо: действующие причины (вклад > 0) простыми словами, по убыванию силы, у каждой слово «сильная» / «заметная» / «слабая».
- Без весов, значений признаков и формул. Строка `P = 1 − …` убрана из карточки клиента и из панели риска услуги.
- Таблица «значение / вес / вклад» и формула для проверки остаются на странице «О модели» и в API; в блоке — ссылка «Как считается риск» на «О модели».

Вне изменения:
- Расчёт, веса и данные API не меняются.
- Страница «О модели» не меняется.

## Затронутые части

- backend: нет
- frontend: `pages/customer` (FeaturesCard → блок причин по услугам, ServiceRiskPanel), `entities/customer-detail` (группировка и сила причин)
- контракт `api/openapi.yaml`: нет
- защищённые пути: `e2e/tests/demo.spec.ts` — только если демо-тест проверяет формулу или таблицу весов в карточке; причина — слова эксперта 25.10
- зависит от: нет

## Связанные решения

- ADR-0001: объяснимый скор. Объяснение в карточке — причинами словами по услугам; проверка до цента остаётся на «О модели» и в эталоне.
- Макет: нет [ПРЕДПОЛОЖЕНО — фриз, этап 9].
