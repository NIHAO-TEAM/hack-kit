# Дизайн: разнос обработчиков

## Подход

Перенос методов без правки тел: методы одного типа Go могут лежать в разных файлах пакета. `engine.go` из `recalc-engine` не трогается.

## Допущения

- [ПРОВЕРЕНО] Обработчики `analytics` сейчас в `http.go`.

## Решения по ходу

- Правило depguard `domain-no-io` (`backend/.golangci.yml`) пускает `net/http` только в `http.go`, `service.go`, `projection.go`; новые файлы с обработчиками его импортировать не могут (CI `go-lint` упал). Гейт не ослабляю: алиасы `responseWriter` и `request` объявлены в `http.go`, файлы по возможностям используют их. Сигнатуры методов те же (алиасы типов). Если ревьюер предпочтёт добавить файлы в исключения правила — это отдельное «да» человека.
