# Дизайн: вход — заголовки и орбита

## Подход

1. **Заголовки.** В `LoginPage.tsx` убрать `<div className={classes.mark}><AezaMark size={56}/></div>`; на его месте `<Text component="div" ta="center" fw={700} size="xl">Контур удержания</Text>` с нижним отступом; `<Title order={1} size="h3">` в карточке — «Личный кабинет». Класс `.mark` и импорт `AezaMark` в этом файле удалить, если больше не нужны.
2. **Блюр.** В `LoginPage.module.css`: `.planet { filter: blur(30px) }`, `.glow { filter: blur(56px) }`. Проверить на глаз и axe обе темы.
3. **Орбита.** Внутри `.backdrop` слой `.orbit` с центром в центре планеты (те же `right`/`bottom`, размер около 1,3 от планеты), внутри — SVG-эллипс (`<ellipse>` с `fill="none"`, `stroke` `#4CC6F1` с `stroke-opacity` около 0,35, `stroke-width` 1.5) под наклоном (`transform: rotate(-18deg)` у слоя) и `.satellite` — круг 8 px с `box-shadow`, движущийся по тому же эллипсу: `offset-path: path('…')` по эллипсу (значения подобрать по размеру) и `@keyframes orbit { to { offset-distance: 100%; } }` с `animation: orbit 45s linear infinite`. Если `offset-path` на нужных браузерах не работает, допустимо вращение обёртки (`rotate`) с обратным поворотом спутника, чтобы он оставался круглым.
4. **Движение и доступность.** `@media (prefers-reduced-motion: reduce) { .satellite { animation: none; } }`. Слой `aria-hidden`, позади формы, без `will-change` на больших слоях; только `transform` или `offset-distance`.
5. **Тест.** `LoginPage.test.tsx`: заголовок уровня 1 — «Личный кабинет», на странице есть текст «Контур удержания» вне заголовка; фон `aria-hidden`; значка `AezaMark` на странице входа нет.
6. **Проверка.** `pnpm check`; после слияния `deploy-a11y.yml` (обе темы, 1440 и 390), `deploy-layout.yml` (вход без горизонтальной прокрутки), `Demo e2e`, дымовая проверка — зелёные.

## Допущения

- [ПРЕДПОЛОЖЕНО] «Буква л» — это значок aéza над формой (белая «é» в тёмном квадрате); значок в шапке владелец не упоминал, остаётся.
- [ПРЕДПОЛОЖЕНО] Орбита — тонкий эллипс со спутником, а не вращение самой планеты; планета остаётся статичной.

## Риски

- Постоянная анимация дольше 5 с на входе: она декоративная, не мешает чтению формы, при `prefers-reduced-motion` отключается; осознанное решение владельца.
- Ничего не должно перекрывать форму и подписи; проверка скриншотами обеих тем на 1440 и 390.
