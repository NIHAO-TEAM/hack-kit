# README для жюри: прод, роли, где смотреть каждый критерий

## Зачем

Сдача — «репо + публичный домен» (эксперт aéza, `docs/experts/2026-10-23-aeza-chat.md`), учётки жюри — организаторам вместе со сдачей. Жюри проверяет «всё, от системного дизайна до деплоя в прод»; у него минуты на проект. Сейчас README описывает локальный запуск (`README.md`, раздел «Запуск»), но не отвечает на вопрос жюри «где на проде посмотреть X».

## Что меняется

- В начале README — блок «Для жюри»: ссылка на прод, роли и что каждая видит (без паролей: «пароли — в материалах сдачи»), путь демо в 5 шагов со ссылками на экраны.
- Таблица «критерий → где посмотреть на проде → где в репо» по пяти критериям `docs/scale.md` (очередь и деньги, «О модели» и оракул, Helm/k3s и `values.yaml`, Grafana/Prometheus и замеры `docs/load/`, Swagger).
- «Встроить в контур aéza»: какие ключи `deploy/helm/churn/values.yaml` менять (источник REST, OIDC, Prometheus) — сверено с чартом.
- Раздел «Дополнительно» сверен с `main`: только то, что реально слито и работает на проде.
- Все ссылки README проверены (локальные пути существуют, внешние отвечают).

Вне изменения:
- Слайды, видео, текст питча — работа людей и пахана (этап фриза).
- Пароли и токены в README — никогда.
