# Дизайн: README для жюри

## Подход

- README сверху вниз: «Для жюри» (прод, роли, демо за 5 шагов) → таблица критериев → «Встроить в контур aéza» → локальный запуск (как сейчас) → остальное.
- Каждая строка таблицы критериев — ссылка на экран прода и на файл/PR в репо; факт проверен на проде или в `main`, иначе строки нет.
- Проверка ссылок — скрипт или `lychee`/`markdown-link-check` локально; итог в PR.

| Вариант | Почему нет |
