# queue-ui: изменения сценариев

## ADDED

### Requirement: очередь удержания

#### Scenario: открыть очередь

- WHEN маркетолог открывает «Очередь» на данных организаторов
- THEN сверху ожидаемая потеря 3 879,73 € с подписью, первым в таблице клиент 9 с действием «Пополнить · −1 067,48 €»

#### Scenario: сортировка

- WHEN маркетолог дважды нажимает заголовок «Баланс»
- THEN таблица сортируется по балансу по возрастанию, затем по убыванию

#### Scenario: нет оценки

- WHEN у клиента нет оценки или он потерян
- THEN строка внизу, вместо скора — «нет оценки» или «потерян» с причиной
