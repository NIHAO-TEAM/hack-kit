# grafana: изменения сценариев

## ADDED

### Requirement: дашборд «Внутри сервиса»

Grafana SHALL показывать дашборд «Внутри сервиса» с рантаймом Go, пересчётом, этапами приёма снимка, HTTP по маршрутам и потоком событий; каждая панель ссылается только на метрики, которые отдаёт сервер.

#### Scenario: нагрузочный замер

- WHEN идёт поток событий эмулятора
- THEN на дашборде видны событий/с, горутины, куча, паузы GC и длительность пересчёта
- Тест: тест соответствия запросов дашборда метрикам сервера

## REMOVED

### Requirement: панели «Работа с клиентами»

Причина: ADR-0004, п. 1 — цикла задач в интерфейсе нет.
