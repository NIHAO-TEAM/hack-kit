# Дизайн: нестабильный тест очереди

## Подход

1. Найти файл настройки тестов клиента (`setupFiles` в конфиге `vitest`) и добавить `configure({ asyncUtilTimeout: 5000 })` из `@testing-library/react`.
2. Прогнать `pnpm check` не меньше трёх раз подряд (и `pnpm vitest run src/app/queue.test.tsx` пять раз) — все зелёные.
3. Для сравнения: общий таймаут теста Vitest не трогать.

## Допущения

- [ПРЕДПОЛОЖЕНО] Причина — медленный первый рендер, а не гонка в коде очереди. Если три прогона подряд после правки всё ещё дают красный, значит причина другая: исполнитель описывает её в «Найдено по ходу» и не скрывает тест.

## Риски

- Слишком большое ожидание маскирует настоящий зависший экран: 5 с на один шаг — потолок, дольше не ставить.
