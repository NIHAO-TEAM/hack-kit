# Очередь на планшете: спрятанные заголовки не растягиваются

## Зачем

После `queue-sort-tablet` (#129) `deploy-layout.yml` на 5c422c1 красный одним нарушением: «очередь · 820px · сортировка «ID»: 30×44 px». До 64em заголовки таблицы спрятаны (1×1 px, «Найдено по ходу» #129), сортировку там даёт новый блок `SortControl`. Но #129 добавил `.sort { min-height: 44px }` в медиазапрос `width <= 64em` (`frontend/src/pages/queue/ui/QueueTable.module.css:196`): спрятанная кнопка «ID» выросла до 30×44, и тест, который пропускает спрятанные (почти нулевые) элементы, стал её мерить. Без зелёного прогона нельзя заявлять шкалу 5.9 («цели касания от 44 px»).

## Что меняется

- Правило `.sort { min-height: 44px }` для `width <= 64em` убрано: заголовки там спрятаны, крупные цели — у `SortControl`. `.take` (44 px) остаётся.
- Спрятанные кнопки заголовков не получают фокус с клавиатуры на узком экране (`tabIndex=-1` или `display: none` вместо визуального скрытия), чтобы клавиатура не попадала в невидимые элементы; читалке экрана сортировку даёт `SortControl`.
- `deploy-layout.yml` после слияния зелёный.

Вне изменения:
- Вид очереди шире 64em и `SortControl` — без изменений.

## Затронутые части

- frontend: `pages/queue/ui/QueueTable.module.css`, при необходимости `QueueTable.tsx`
- контракт `api/openapi.yaml`: нет
- защищённые пути: нет
- зависит от: нет
