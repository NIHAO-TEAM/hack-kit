# Дизайн: кнопка SSO по флагу

## Подход

1. Контракт: `GET /api/v1/auth/config`, `security: []`, ответ `AuthConfig { ssoEnabled }`; `make generate`.
2. Сервер: `ssoEnabled` = OIDC сконфигурирован (тот же признак, по которому `oidcLogin` отвечает `501`).
3. Фронт: запрос на экране входа; кнопка только при `true`; ошибка запроса — кнопки нет, вход по паролю работает.
4. Если список открытых путей проверяет сторож в `tests/invariants/`, правку делает человек; исполнитель пишет запись в «Найдено по ходу».

## Допущения

- [ПРЕДПОЛОЖЕНО] Флаг не раскрывает адрес провайдера и другие настройки — только `boolean`.

## Риски

- `sso-verify` (#84) правит `LoginPage` — поэтому зависимость.
