# Дизайн: GET /version

## Подход

Обработчик `version` рядом с `healthz` в `backend/cmd/api`, регистрация `GET /version` в `newMux()`. Значение `APP_VERSION` читается при каждом запросе через `os.Getenv`, чтобы тест мог подменять его через `t.Setenv`. Тело — `encoding/json`, как у `/healthz`. Остальные методы `ServeMux` отклоняет сам (`405` с `Allow`).

## Отброшенные варианты

| Вариант | Почему нет |
|---|---|
| Читать переменную один раз при старте | Тест не сможет проверить значение по умолчанию и подменённое в одном процессе |
| `-ldflags` при сборке | Нужен Dockerfile и сборочный скрипт, которых в заглушке нет |

## Допущения

- [ПРЕДПОЛОЖЕНО] Пустая строка в `APP_VERSION` считается «не задана».
