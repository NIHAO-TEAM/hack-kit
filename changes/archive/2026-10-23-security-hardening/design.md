# Дизайн: Безопасность: заголовки, зависимости, секреты

## Подход

- Заголовки — промежуточный слой в `httpx`, подключение — одна строка в `internal/app`.

## Решения по ходу

- Встроенный скрипт темы в `frontend/index.html` и запуск Swagger UI в `docs.go` противоречили CSP без `unsafe-inline`: вынесены в `frontend/public/theme-init.js` и `assets/init.js`. `docs_test.go` в `cmd/api` подогнан под это (не гейт, проверка та же).
- `style-src 'unsafe-inline'` оставлен: Mantine и Swagger UI ставят стили атрибутами. Требование касается только скриптов.
- [ПРЕДПОЛОЖЕНО] Мета CSP во фронте не нужна: заголовок ставит сервер.
- Caddy уже ставит часть заголовков; значения совпадают по смыслу, `header` в Caddy переопределяет, конфликта нет.
- gitleaks по истории и `govulncheck` в среде запустить нельзя (нет утилиты и доступа к vuln.go.dev): govulncheck прогонит CI, gitleaks — вне среды.
