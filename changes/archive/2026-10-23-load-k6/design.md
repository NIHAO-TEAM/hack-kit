# Дизайн: Нагрузка: 100k клиентов, замеры в `docs/load/`

## Подход

- Прогон локально в Compose и один раз на проде (вне часов демо); метрики `churn_recalc_duration_seconds` подтверждают числа.

## Решения по ходу

- Расхождение: задача требует числа и повторный прогон, а в среде исполнителя нет Docker и k6. Выбрано: сценарии и инструкция без чисел, в README явно «не измерено» (критерий честных оговорок важнее красивой таблицы). [ПРЕДПОЛОЖЕНО] Параметры входа (`LOGIN`/`PASSWORD`, cookie jar) взяты из контракта, живым сервером не проверены.
