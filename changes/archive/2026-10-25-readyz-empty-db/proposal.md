# Готовность на пустой базе: чистая установка Helm-чартом не падает по таймауту

## Зачем

`Deploy chaos` (#157) на `main` c196acd красный (прогон 40132614696): `helm install --atomic` ждал готовности подов 10 минут и откатился. Проверено по логу и коду: `/readyz` отвечает 200, только когда есть результат пересчёта (`cmd/api/main.go`: `recalc.Engine.Latest() != nil`), а на пустой базе пересчёт заканчивается ошибкой «снимок ещё не загружен» — результата нет никогда, поды не становятся готовыми, а снимок грузится уже в готовый сервис. На проде не видно (снимок в базе есть), но чистая установка в контур aéza Helm-чартом (шкала 3.9, «встраивание правкой `values.yaml`») упадёт так же.

## Что меняется

- Движок пересчёта хранит ошибку последнего завершённого прогона (`Engine.LastError`).
- `/readyz`: готов, если есть результат, **или** последний прогон закончился `source.ErrNoSnapshot` (считать нечего). Любая другая ошибка пересчёта — по-прежнему не готов; проверка базы (`Ping`) не меняется.

Вне изменения:
- Порядок остановки, `/healthz`, пробы Helm.

## Затронутые части

- frontend: нет
- контракт `api/openapi.yaml`: нет
- защищённые пути: нет
- зависит от: нет
