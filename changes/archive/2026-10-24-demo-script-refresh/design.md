# Дизайн: демо-сценарий

## Подход

1. Пройти текущий `demo.spec.ts` и `demo-script.md` по `main`; таблица «шаг — есть в продукте — проверяется тестом» в «Найдено по ходу».
2. Каждый шаг живого демо — `test.step` с ролью и проверкой того, что видит жюри (текст, число из golden).
3. Поток событий в тесте: 2 500 событий со скоростью «как можно быстрее» (если предел позволяет) и ожидание итога, таймаут с запасом.
4. Grafana — только проверка, что ссылка «Мониторинг» есть и ведёт на `/grafana/` (сам Grafana в стенде раннера может отсутствовать — тогда проверка ссылки).

## Риски

- Длительность `Demo e2e` растёт: держать шаги короткими, общий таймаут прогона не больше 15 мин.
