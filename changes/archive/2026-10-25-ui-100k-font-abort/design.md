# Дизайн: отмена загрузки шрифта в проверке экранов 100k

Фильтр рядом с `sseClosed`: `/downloadable font: download failed.*status=2152398850/`. Сообщение остаётся в журнале шагов (`UI_100K_LOG`) строкой «шрифт: загрузка прервана переходом», чтобы было видно, сколько раз это случилось.

## Допущения

- [ПРЕДПОЛОЖЕНО] Статус `2152398850` в Firefox означает только `NS_BINDING_ABORTED` (отмена запроса), а не ошибку сервера: ответы 4xx/5xx Firefox сообщает другими статусами, и `failedApi` в тесте ловит 5xx отдельно.
