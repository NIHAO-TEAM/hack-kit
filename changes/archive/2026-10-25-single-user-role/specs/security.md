# security

### Requirement: маркетолог и аналитик — один пользователь

Роли `marketer` и `analyst` SHALL иметь одинаковые права: работа с клиентом, модель, источник, журнал. Права проверяются на сервере для каждой операции.

#### Scenario: маркетолог меняет вес

- WHEN `marketer` отправил `PATCH /api/v1/model/settings`
- THEN ответ 200, запись в журнале от `marketer`

#### Scenario: аналитик берёт клиента в работу

- WHEN `analyst` отправил `POST /api/v1/customers/{id}/task`
- THEN ответ 200 (раньше 403)

#### Scenario: подпись роли

- WHEN вошёл `marketer` или `analyst`
- THEN в интерфейсе роль подписана «пользователь», в меню все разделы: «Очередь», «Сводка», «Модель», «Источник», «О модели»

#### Scenario: без сессии

- WHEN запрос без сессии
- THEN 401, как раньше
