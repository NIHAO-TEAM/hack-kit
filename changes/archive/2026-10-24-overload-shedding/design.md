# Дизайн: быстрый отказ под перегрузкой

## Подход

1. `type limiter struct{ sem chan struct{}; wait time.Duration }`; `select` на `sem <- struct{}{}`, `time.After(wait)`, `r.Context().Done()`.
2. Класс запроса — по операции из `operations` (`auth`), как права: чтение, запись, приём. Таблица в коде рядом с правами, тест «каждая операция имеет класс».
3. Проверить, что `lifecycle.go` (`/readyz`, остановка) не попадает под предел.
4. Значения по умолчанию — по замеру k6 `read.js` после `read-model-index`; до него — консервативные.

## Допущения

- [ПРЕДПОЛОЖЕНО] `503` лучше `429` для перегрузки сервера: `429` — про клиента, `503` — про сервер (RFC 9110).

## Риски

- Слишком низкий предел режет нормальный трафик демо: проверить на сценарии `Demo e2e` и k6 `read.js` (0 % `503` при 10 VU).
