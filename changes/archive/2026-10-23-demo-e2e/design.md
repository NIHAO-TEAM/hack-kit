# Дизайн: e2e демо-сценария на стенде (Playwright)

## Подход

- Firefox, как в `frontend/AGENTS.md`; учётки — из переменных окружения, не из репозитория.

## Решения по ходу

- [ПРЕДПОЛОЖЕНО] Данные и правки аналитика идут через API (`request` второго контекста), проверки маркетолога — через UI и API. Так тест не зависит от вёрстки формы «Модель».
- [ПРЕДПОЛОЖЕНО] Пароли `marketer`/`analyst` — `E2E_MARKETER_PASSWORD`, `E2E_ANALYST_PASSWORD`; без них тест пропускается.
- [ПРЕДПОЛОЖЕНО] `reset` эмулятора возвращает данные, но не настройки модели, поэтому тест явно ставит `noauto = 0,55` до и после.
- Тест не запускался: в среде нет Firefox и стенда. Прогоны — на стенде.
