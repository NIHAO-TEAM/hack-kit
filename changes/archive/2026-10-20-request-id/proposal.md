# Идентификатор запроса: заголовок X-Request-Id

## Зачем

Чтобы связывать запись в логах с запросом жюри или клиента. Это же — тестовое изменение B для проверки цепочки hack-kit: подключение новой библиотеки с проверкой по Context7, конфликт с параллельным PR, перезапуск исполнителя после обрыва.

## Что меняется

- Каждый ответ API содержит заголовок `X-Request-Id`, включая `405` и `404`.
- Если запрос пришёл с корректным UUID в `X-Request-Id`, он возвращается как есть.
- Если заголовка нет или значение не UUID, генерируется новый UUID v4.

Вне изменения:
- Запись идентификатора в логи и трассировка.
- Передача идентификатора во внешние вызовы.
