# Адаптер REST-биллинга: данные сами приходят из API

## Зачем

Эксперт aéza: данные в реальности приходят из «рест апи». Кейс: «реальные данные поступают в систему в режиме реального времени произвольным способом».

## Что меняется

- При заданном `BILLING_URL` модуль `source` раз в `BILLING_POLL_SECONDS` забирает снимок той же формы, что `data.json` (`Authorization: Bearer BILLING_TOKEN`), сравнивает с текущим и при отличии пишет новый снимок (`source = api`).
- Сбой источника не стирает данные: «данные от 12:40», счётчик ошибок в `/metrics`.
- Ручной `PUT /source/snapshot` главнее: после него опрос на паузе, пока его не включат на экране «Источник».
- На стенде — `mock-billing` в Compose (отдаёт файл набора), подпись «адаптер под наш контракт: формат API aéza неизвестен».

Вне изменения:
- Курсор `updatedAt` — не делаем (вердикт).

## Затронутые части

- backend: `internal/source` (новый `adapter.go`)
- frontend: переключатель опроса на `pages/source`
- контракт `api/openapi.yaml`: добавления в этом PR, если нужны (без поломки)
- защищённые пути: да — `deploy/` (mock-billing), разрешено
- зависит от: `billing-emulator`, `source-screen`
