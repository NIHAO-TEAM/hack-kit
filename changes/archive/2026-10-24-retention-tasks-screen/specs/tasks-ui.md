# tasks-ui: изменения сценариев

## ADDED

### Requirement: список задач удержания

Экран «Задачи» SHALL показывать задачи с фильтрами и сроками.

#### Scenario: мои задачи

- WHEN маркетолог открывает «Задачи»
- THEN выбран фильтр «Мои», видны его открытые задачи со сроком и ссылкой на карточку

#### Scenario: клиент пропал из снимка

- WHEN по задаче клиента нет в текущем снимке
- THEN строка с пояснением «клиента нет в текущем снимке», без ссылки

### Requirement: напоминание о сроке

#### Scenario: срок сегодня

- WHEN у маркетолога 2 открытые задачи со сроком сегодня и 1 просроченная
- THEN в шапке «Сроки: 3», по клику — список со ссылками

#### Scenario: задачу закрыли

- WHEN одну из задач закрыли на другом экране
- THEN счётчик становится 2 без перезагрузки
