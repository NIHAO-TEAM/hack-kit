# source: изменения сценариев

## ADDED

### Requirement: пачка событий извне

Сервер SHALL принимать пачку событий биллинга `POST /source/events` (NDJSON или массив) тем же конвейером, что события эмулятора, не применяя повторно событие с уже принятым `eventId`.

#### Scenario: повтор пачки

- WHEN биллинг отправляет ту же пачку из 500 событий дважды
- THEN первый ответ `accepted = 500`, второй `duplicate = 500`, данные изменились один раз
- Тест: интеграционный тест идемпотентности

#### Scenario: перегрузка

- WHEN очередь приёма полна дольше 1 с
- THEN ответ `503` с `Retry-After`, ни одно событие запроса не применено
- Тест: тест обратного давления
