# web-shell: изменения сценариев

## ADDED

### Requirement: вход в панель

Панель SHALL пускать только вошедшего пользователя.

#### Scenario: открыть панель без входа

- WHEN браузер без сессии открывает любую страницу панели
- THEN показывается экран входа; после верного логина и пароля открывается стартовая страница роли

#### Scenario: неверный пароль

- WHEN пользователь вводит неверный пароль
- THEN под формой текст «Неверный логин или пароль», поля сохраняют логин

#### Scenario: слишком много попыток

- WHEN сервер ответил `429`
- THEN текст объясняет, через сколько минут можно повторить

### Requirement: навигация по роли

#### Scenario: маркетолог

- WHEN входит пользователь роли `marketer`
- THEN в навигации «Очередь» и «Сводка»; разделов «Модель» и «Источник» нет

#### Scenario: прямой переход без права

- WHEN маркетолог открывает адрес раздела «Модель»
- THEN экран «Недостаточно прав» с объяснением, у кого этот раздел есть

#### Scenario: выход

- WHEN пользователь нажимает «Выйти»
- THEN сессия завершена, показывается экран входа, кнопка «назад» не возвращает в панель

### Requirement: работа без бэкенда

#### Scenario: моки

- WHEN фронт запущен в режиме моков
- THEN вход и навигация работают на данных организаторов без запущенного API
