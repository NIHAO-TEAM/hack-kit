# Дизайн: оракул модели

## Подход

Основа — `prototype_r2.py` (в этой папке). Его вывод на `cases/analizator/data.json` — финальные цифры дебатов: уровни 3 / 2 / 1 / 4 (высокие №10, 5, 9; средние №4, 1; низкий №6; потеряны №2, 3, 7, 8), ожидаемая потеря 3 879,73 €, под угрозой 6 900,46 €, уже потеряно 7 368,34 €, №9 — 3 459,27 € [ПРОВЕРЕНО пахан, 23.10]. Оракул переписывает прототип чисто и параметризует, не меняя правил.

**Правила (их и записать в `docs/model-rules.md`):**

- Живые: `active`, `suspended`, `prolong_wait`. Клиент без услуг — `unscored`; все услуги не живые — `lost`.
- Списания в окне `[asOf, asOf + h)`: `prolong_wait` — 1 (долг); `hour` — `h` часов (720 за 30 дней, 168 за 7 дней); остальные — шаги периода от `max(expiresAt, asOf)`, календарно, день не больше последнего дня месяца.
- `R` услуги = `price × списаний(720 ч)`; при `priceBasis = per_month` у `hour` — `price` за 720 часов (настройка, по умолчанию `per_period`).
- Признаки (`f ∈ [0, 1]`):
  - `pwait` — `prolong_wait`: `1 − осталось/5 дн`, срок вышел → 1;
  - `funds` — на аккаунт: нужно = Σ `price × списаний(168 ч)` по `active` и `suspended` + Σ `price` по `prolong_wait`; есть = `balance` + `bonusBalance` при `bonusState = unlocked`; `f = max(0, (нужно − есть)/нужно)`;
  - `noauto` — `autoProlong = false`: `0` при > 7 дн до `expiresAt`, иначе `min(1, 1 − дней/7)` (срок прошёл → 1);
  - `fail` — доля `not_performed` среди транзакций `prolong` услуги;
  - `susp` — `suspended` → 1;
  - `flight` — `withdrawBalance / balance` (баланс 0 → 0).
- Веса по умолчанию: `pwait 0,80`, `funds 0,70`, `noauto 0,55`, `fail 0,40`, `susp 0,35`, `flight 0,15`.
- `P = 1 − Π(1 − wᵢ·fᵢ)`; скор = `100 · max P` по живым; уровни: `high ≥ 70`, `medium ≥ 50`, иначе `low`.
- Ожидаемая потеря = Σ по живым `round(P · R)` (до цента на услугу, дальше целые); под угрозой = Σ `R` клиентов `high` и `medium`; уже потеряно = Σ `price × списаний(720 ч)` не живых услуг (как если бы были активны).
- Действия с ценой: «пополнить на (нужно − есть)» при `funds > 0`; «включить автопродление» при `noauto > 0`; эффект = потеря после применения к копии − потеря до. Эталон: №9 пополнить на 529,84 € → −1 067,48 €; №1 автопродление → −365,29 €, скор 56,02 → 41,57.

**Формат golden:** `{asOf, settings, customers: [{id, state, score, level, expectedLossCents, exposureCents, lostCents, features: {svcId: {id: f}}, actions: [...] }], summary: {...}}`; числа скора — с 2 знаками, деньги — целые центы.
