# Дизайн: проверки качества данных на экране источника

## Подход

- Сервер: в `GetSourceStatus` пройти по реестру проверок `risk` (`RegisterCheck`) на текущем снимке и времени модели; для каждой — `ok = нет срабатываний`, `message` — текст проверки и число услуг, `items` — до 10 `{serviceId, accountId}`.
- Если пересчёт уже хранит результаты проверок (`recalc.go`, `qualityCounts`) — брать оттуда, а не считать заново [ПРЕДПОЛОЖЕНО: проверить по `internal/app/recalc.go`].
- Фронт: `QualityChecks.tsx` рисует `checks`; словарь `titles` в `model/quality.ts` удалить, тест на подписи переписать на данные сервера.

## Отброшенные варианты

| Вариант | Почему нет |
|---|---|
| Поправить словарь кодов во фронте | коды продолжат расходиться при новой проверке; текст уже есть на сервере |
| Отдельный путь `/source/quality` | `checks` уже есть в контракте `SourceStatus` |

## Допущения

- [ПРОВЕРЕНО] Три проверки: `stale_status`, `blocked_future`, `suspended_expired`.
- [ПРЕДПОЛОЖЕНО] На наборе организаторов срабатывает `stale_status` (эксперт: устаревшие `prolong_wait` — ошибка генератора).

## Фронт

- Состояния: загрузка, все проверки пройдены («Противоречий не найдено»), найдены, ошибка загрузки статуса.
- Роль: аналитик и `jury` (экран «Источник»), маркетолог — «Недостаточно прав», как в #63.

## Риски

- Расчёт проверок на большом снимке в каждом `GET /source/status` — медленно; поэтому сначала брать результат пересчёта.

## Решения по ходу

- [ПРОВЕРЕНО по коду] Результаты проверок хранит пересчёт (`risk.Result`), но только как тексты в `qualityCounts`. Добавлен `Result.Checks` (id, ok, текст со счётчиком, до 10 услуг); `/source/status` берёт его из `Recalc.Engine.Latest()`, если `DataVersion` совпала с версией снимка, иначе `checks=[]`. Модуль `source` ядра не импортирует (depguard): функцию передаёт сборка сервера (`SourceAPI.WithChecks`).
- Текст: у проверки метод `Subject()`; сообщение — «N услуг(а/и) <Subject>» или «Нет услуг <Subject>».
- Фронт читает `checks` из `statusQuery`; запрос сводки на экране «Источник» убран.
