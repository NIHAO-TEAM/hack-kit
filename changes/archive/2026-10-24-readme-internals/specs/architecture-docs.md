# architecture-docs: изменения сценариев

## ADDED

### Requirement: README объясняет внутренние механизмы

`README.md` SHALL содержать раздел «Как это устроено внутри» со схемой потоков, путём события, таблицей «механизм → файл → проверка → число» и разделом о выборе в пользу Go; каждое число и каждая ссылка проверяемы.

#### Scenario: ссылки

- WHEN открыт любой путь или якорь из раздела
- THEN файл или якорь существует
- Тест: проверка задачи 2.2 (скрипт проверки ссылок или ручная проверка, записанная в PR)

#### Scenario: числа

- WHEN в README указан замер
- THEN то же число есть в `docs/load/` или golden-файле
- Тест: сверка задачи 1.2
