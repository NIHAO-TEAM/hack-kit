# Дизайн: Описание модели и архитектуры для жюри + экран «О модели»

## Подход

- Чувствительность считается оракулом (`tools/oracle`), числа вписываются в `docs/model.md`.
- Тема и компоненты — ADR-0002 и `design-tokens`; макеты — `docs/design/mockups/`; пять состояний экрана; ключи запросов — корни из `live-updates`.

## Решения по ходу

- Экран «О модели» читает только `GET /model/settings` (веса); значения примера клиента 9 зашиты как подпись к golden: новая ручка в контракте не нужна. [ПРЕДПОЛОЖЕНО]
- Права экрана — `summary.view` (видят все роли, включая `jury`): описание модели не секрет. [ПРЕДПОЛОЖЕНО]
- Веса, которых нет в настройках сервера, берутся из таблицы по умолчанию в странице; сервер главнее. [ПРЕДПОЛОЖЕНО]
- Чувствительность посчитана оракулом (`--settings`), числа в `docs/model.md` взяты из его вывода.
