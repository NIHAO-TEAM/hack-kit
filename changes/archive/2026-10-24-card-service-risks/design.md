# Дизайн: оценки по услугам в карточке

## Подход

1. `CustomerPage` передаёт `detail.serviceRisks ?? []` в `ServiceList`; сопоставление по `serviceId`.
2. Панель услуги переиспользует отрисовку признаков и `formulaText` из `entities/customer-detail` (после `card-score-lost` он принимает вероятность 0..1).
3. Сверка: `Σ lossCents` по `serviceRisks` против `customer.expectedLossCents`; расхождение больше 1 цента — видимое предупреждение (не скрывать).
4. Моки: `serviceRisks` для клиента 9 из `testdata/golden` (не выдуманные числа).
