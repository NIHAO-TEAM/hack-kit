# Дизайн: окно спасения по времени модели

## Подход

1. `CustomerPage` запрашивает сводку тем же хуком, что `QueuePage` (`summary.data?.asOf`); кеш запроса общий, лишнего запроса при переходе из очереди нет.
2. `ServiceList` принимает `asOf: string | null` обязательным пропом; `null` — подпись «время модели загружается» вместо полосы.
3. Живые обновления: сводка уже обновляется по событию пересчёта, таймер карточки сдвигается вместе с очередью.

## Допущения

- [ПРЕДПОЛОЖЕНО] `asOf` сводки — время модели текущего снимка (`specs/source`, «время модели из снимка»); отдельный `/api/clock` не нужен.

## Риски

- Нет.

## Решения по ходу

- Запрос сводки перенесён из `pages/queue/api` в `entities/summary`, чтобы карточка и очередь делили один ключ кеша без импорта между страницами (steiger). Поведение очереди не меняется.
