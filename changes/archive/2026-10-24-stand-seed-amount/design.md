# Дизайн: сид стенда

## Подход

1. Заменить `amount: 1200` на сумму ≤ 1000 (или две транзакции), сверить, что ручной клиент остаётся в той же роли (см. описание стенда в `docs/demo-script.md`).
2. Тест: прогнать `seedBody()` при `SEED_STAND=true` через `validate` снимка.
3. Если `validate` не проверяет `amount` — добавить, с текстом ошибки по-русски и полем.

## Допущения

- [ПРЕДПОЛОЖЕНО] Смысл транзакции 1200 — «крупное пополнение»; заменяется двумя по 600.

- Расходилось: проверка `amount` 0–1000 в `validate.go` уже есть (задача 1.2 — только добавлен случай `-1`); `TestStandSeedParses` проверки не запускал (`ParseSnapshot` без `Validate`). Выбрал: новый `TestStandSeedValidates` гоняет `Validate` по склейке сида; без правки `stand.json` он падает с `сумма 1200 вне 0..1000`.
- [ПРЕДПОЛОЖЕНО] Вместо двух по 600 — одна транзакция на 1000: число транзакций стенда (105) и golden `stand.json` (оракул) не меняются, `TestGolden` зелёный. Цена услуги 1006 остаётся 1200.
