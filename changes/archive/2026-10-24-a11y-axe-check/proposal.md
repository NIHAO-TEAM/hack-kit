# Доступность: axe на всех экранах ролей, обе темы, в CI после выката

## Зачем

Шкала 5.9: «Клавиатура, подписи полей, контраст AA (проверен автотестом)». Сейчас автотеста нет: `@axe-core/playwright` стоит в `frontend/package.json`, но используется только в `frontend/scripts/screenshots.mjs` — это шаблон кита с чужими маршрутами (`/points/demo/stock`), без входа, в CI не запускается. Утверждать «контраст проверен» жюри нельзя.

## Что меняется

- `e2e/tests/a11y.spec.ts`: вход `jury` (`E2E_JURY_PASSWORD`), обход экранов — вход, очередь, карточка клиента 9, сводка, модель, источник, «О модели» (и «Задачи», если маршрут уже есть в `main`), тёмная и светлая тема, ширина 1440 и 390. Нарушения axe уровня `serious` и `critical` (WCAG 2 AA, включая `color-contrast` и подписи полей) — тест красный, в выводе — экран, тема, правило, элемент.
- Новый workflow `.github/workflows/deploy-a11y.yml`: после `Deploy smoke` на `main` гоняет `a11y.spec.ts` по проду, скриншоты нарушений — в артефакты. Существующие workflow и гейты не меняются.
- Найденные нарушения исправлены во фронте (токены темы, подписи, `aria-label`) — в этом же изменении, если их до 10; больше — первые 10 по экранам демо, остальные — в «Найдено по ходу».
- `frontend/scripts/screenshots.mjs`: маршруты по умолчанию — экраны этого продукта, вход через переменные окружения (для `frontend-design-review`).
- README, «Безопасность» / «Дополнительно»: строка «доступность: axe, WCAG 2 AA, обе темы, проверяется после каждого выката».

Вне изменения:
- Цели касания 44 px и клавиатурные сценарии — только то, что ловит axe; ручная проверка клавиатуры — нет.

## Затронутые части

- e2e: `e2e/tests/a11y.spec.ts`
- `.github/workflows/deploy-a11y.yml` (новый)
- frontend: тема (`shared/ui/theme`) и точечно экраны с нарушениями, `scripts/screenshots.mjs`
- контракт `api/openapi.yaml`: нет
- защищённые пути: да — `e2e/`, новый `.github/workflows/deploy-a11y.yml`; причина: автотест доступности по шкале 5.9 на проде
- зависит от: нет

## Связанные решения

- ADR: 0002 (тёмная тема — основная, светлая — задуманная)
- Макет: без изменений вида; правятся только цвета, не проходящие AA
