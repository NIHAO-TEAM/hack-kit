# Дизайн: подпись признака bonus_locked

## Подход

1. Текст — из `docs/model-rules.md` (строка признака) и журнала (`Бонусы заблокированы`); вес по умолчанию — из `backend/internal/risk` (golden: `bonus_locked: 0.0`).
2. Тест полноты: список признаков — из того же источника, что golden/мок настроек; для каждого `featureInfo[id]` определён.
3. Порядок признаков на экране не меняется.

## Допущения

- [ПРЕДПОЛОЖЕНО] Подсказка: «Бонусы на счёте нельзя потратить — клиент теряет повод остаться».

## Риски

- Нет.
