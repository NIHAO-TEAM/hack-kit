# Подпись признака «Бонусы заблокированы» на экране «Модель»

## Зачем

Шкала «Вёрстка и дизайн» (9): «Ни одного сырого места: непереведённых ключей, технических id вместо названий». На проде экран «Модель» показывает первым признаком `bonus_locked` с общей подсказкой «Влияет на оценку риска оттока» (скриншот дымовой проверки, run 40043638096): в `featureInfo` (`entities/model-config/model/features.ts`) нет записи для признака из `feature-bonus-locked`. Подпись есть только в журнале (`widgets/audit-log/model/labels.ts`).

## Что меняется

- `featureInfo.bonus_locked`: название, подсказка простыми словами и вес по умолчанию как в `backend/internal/risk`.
- Тест: каждый признак из ответа `GET /model/settings` (мок по `testdata`/golden) имеет запись в `featureInfo` — новый признак без подписи ломает `pnpm check`.

Вне изменения:
- Сервер и контракт — нет.

## Затронутые части

- frontend: `entities/model-config`
- контракт `api/openapi.yaml`: нет
- защищённые пути: нет
- зависит от: нет
