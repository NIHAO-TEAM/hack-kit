# Карточка клиента: причины риска вместо формулы

## Зачем

Эксперт aéza 25.10: «вычисления в UI не требуются»; на уточнение (10:38): «Да, речь о ней [формуле], в целом её лучше убрать или добавить именно Причины… маркетолог-аналитик скорее на глазок анализирует, поэтому ему лучше показать причины риска, а не формулу расчёта».

Проверено по коду: в карточке клиента блок «Признаки риска клиента» — таблица «признак / значение / вес / вклад» и строка `P = 1 − (1 − 0,65·1) · … = 0,9` (`pages/customer/ui/FeaturesCard.tsx`, `formulaText`); та же строка у риска услуги (`ServiceRiskPanel.tsx`, `data-testid="service-formula"`). Шкала: «Полезность для маркетолога», «Объяснимость», «UX».

## Что меняется

- В карточке клиента вместо таблицы с формулой — блок **«Причины риска»**: действующие признаки (вклад > 0) по убыванию вклада, каждый — фраза простыми словами (как в очереди: «Автопродление выключено», «Не хватает средств на продление») и сила словом «сильная» / «заметная» / «слабая» с короткой полосой длины вклада. Без весов, значений и формул.
- Строка формулы `P = 1 − …` убрана из карточки клиента и из панели риска услуги.
- Таблица «значение / вес / вклад» и формула для проверки остаются на странице «О модели» и в API (`GET /customers/{id}`); в карточке — ссылка «Как считается риск» на «О модели».

Вне изменения:
- Расчёт, веса и данные API не меняются.
- Страница «О модели» не меняется.

- ADR-0001: объяснимый скор. Объяснение в карточке — причинами словами; проверка до цента остаётся на «О модели» и в эталоне.
