# customer-ui

### Requirement: карточка объясняет риск причинами по услугам, а не формулой

#### Scenario: причины по услугам

- WHEN пользователь открыл карточку клиента с риском
- THEN виден блок «Причины риска»: услуги с потерей по убыванию потери, у каждой — сумма под угрозой в € и полоса доли в потере клиента; под услугой — причины простыми словами по убыванию силы, у каждой «сильная», «заметная» или «слабая»; весов, значений признаков и строки `P = 1 − …` нет

#### Scenario: без оценки по услугам

- WHEN у клиента нет оценённых услуг, но есть действующие признаки
- THEN причины показаны одним списком без группировки по услугам

#### Scenario: без причин

- WHEN у клиента нет действующих признаков
- THEN в блоке «Явных причин риска нет»

#### Scenario: как считается

- WHEN пользователь нажал «Как считается риск»
- THEN открыта страница «О модели»

#### Scenario: услуга

- WHEN раскрыта услуга клиента
- THEN строки формулы у риска услуги нет
