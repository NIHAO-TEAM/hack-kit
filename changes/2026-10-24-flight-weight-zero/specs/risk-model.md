# risk-model: изменения сценариев

## MODIFIED

### Requirement: признак flight

Признак `flight` SHALL по умолчанию иметь вес 0 и описываться как доступный к выводу реферальный баланс, без утверждения о факте вывода.

#### Scenario: настройки по умолчанию

- WHEN модель считает риск с настройками по умолчанию
- THEN `flight` не влияет на вероятность ни одной услуги
- AND числа сервера совпадают с оракулом до цента

#### Scenario: аналитик включает признак

- WHEN аналитик ставит вес `flight` больше 0
- THEN признак учитывается, причина звучит «Доступно к выводу X из Y на балансе»
