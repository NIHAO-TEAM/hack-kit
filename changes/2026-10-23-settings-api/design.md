# Дизайн: настройки модели

## Подход

- Чтение и запись — `model.Store` (`recalc-engine`), событие `model.changed` публикует `Store.Save`.
- `dryRun`: снимок через `source.SnapshotReader`, `risk.Score` с текущими и черновыми настройками, разница уровней и ожидаемой потери. `model` не импортирует `analytics`.
- Частичная правка сливается поверх текущих настроек.
