# Кнопка SSO только при включённом SSO

## Зачем

Шкала «Вёрстка и дизайн» (9): «Ни одного сырого места». Кнопка «Войти через SSO» показывается всегда; при выключенном SSO (`OIDC_*` не заданы) нажатие ведёт на `501` (находка `keycloak-oidc`). Жюри, запустившее стенд по README без Keycloak, увидит ошибку на первом экране.

## Что меняется

- Новая открытая операция `GET /api/v1/auth/config` → `{ ssoEnabled: boolean }` (без входа, без секретов).
- Экран входа показывает кнопку SSO только при `ssoEnabled: true`; пока ответ не пришёл — кнопки нет.

Вне изменения:
- Поток OIDC — нет.
- Вход по паролю — нет.

## Затронутые части

- backend: `internal/auth`
- frontend: `pages/login`
- контракт `api/openapi.yaml`: да — новая открытая операция (добавление, не ломает)
- защищённые пути: да — `api/openapi.yaml`; причина: новая операция
- зависит от: `sso-verify`
