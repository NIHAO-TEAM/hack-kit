# Версия сборки: GET /version

## Зачем

Стенду и жюри нужно видеть, какая сборка работает. Это же — тестовое изменение A для проверки цепочки hack-kit: красный CI, раунд с замечаниями, правки в той же сессии, слияние.

## Что меняется

- `GET /version` отвечает `200`, `Content-Type: application/json`, телом `{"version":"<значение>"}`.
- Значение берётся из переменной окружения `APP_VERSION`; если она пуста или не задана — `dev`.
- Другие методы на `/version` получают `405`, в заголовке `Allow` есть `GET`.

Вне изменения:
- Сборка с подстановкой версии при компиляции (`-ldflags`), хеш коммита, время сборки.
- Любые другие эндпоинты.

## Затронутые части

- backend: `cmd/api`
- frontend: нет
- контракт `api/openapi.yaml`: нет (файла в заглушке ещё нет)
- защищённые пути: нет
