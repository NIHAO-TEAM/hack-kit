# Дизайн: GET /healthz

## Подход

Обработчик в `backend/cmd/api`, регистрируется в `newMux()` шаблоном `GET /healthz` (маршрутизация по методу из `net/http` Go 1.22+). Для остальных методов `ServeMux` сам отвечает `405` с `Allow`. Тело пишется через `encoding/json`.

## Отброшенные варианты

| Вариант | Почему нет |
|---|---|
| Сторонний роутер | Для одного маршрута лишняя зависимость |
| Тело `ok` текстом | Остальной API будет JSON, проверки деплоя проще с одним форматом |

## Допущения

- [ПРОВЕРЕНО] `go 1.24` в `backend/go.mod` — шаблоны маршрутов с методом доступны.

## Риски

- Нет.
