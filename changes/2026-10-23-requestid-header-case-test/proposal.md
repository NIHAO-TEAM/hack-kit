# X-Request-Id: регистр имени заголовка

## Зачем

Тест I (23.10): проверка исполнителей exec-4 и exec-5 и поля «Доступен» (exec-1…3 временно «нет»). Имя заголовка HTTP нечувствительно к регистру; фиксируем это для X-Request-Id.

## Что меняется

- Тест: запрос с заголовком `x-request-id: <uuid>` (нижний регистр имени) → в ответе `X-Request-Id` равен этому UUID. Код сервера не меняется.

Вне изменения:
- Код обработчиков, контракт, другие тесты.
