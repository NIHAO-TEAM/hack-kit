# Задачи: пересчёт конвейером

Каждая задача проверяема: в конце строки — чем проверить.

## 1. Измерение

- [ ] 1.1 `BenchmarkRecalc10k` и `BenchmarkRecalc100k`, профиль cpu и alloc до правки — проверка: вывод `go test -bench -benchmem` и три главных места профиля в «Найдено по ходу»

## 2. Конвейер и отмена

- [ ] 2.1 Пул воркеров по пачкам, запись результатов по индексу без общей блокировки — проверка: тест равенства с последовательным расчётом (набор организаторов и 10k)
- [ ] 2.2 Отмена пересчёта через `context` при новом снимке или настройках, публикация только завершённого актуального прогона — проверка: тест «второй снимок отменяет первый пересчёт»
- [ ] 2.3 Склеивание отмен при потоке событий (флаг `dirty`), пересчёт успевает завершиться — проверка: тест потока из 2 500 событий
- [ ] 2.4 `sync.Pool` там, где профиль показал выигрыш — проверка: бенчмарк до и после (выделения на операцию)
- [ ] 2.5 Метрики: воркеры, `churn_recalc_cancelled_total`, длительность пачек — проверка: тест метрик

## 3. Профилирование и отчёт

- [ ] 3.1 Служебный маршрут `pprof` только по токену метрик — проверка: тест `401/403` без токена, `200` с токеном

- [ ] 3.3 Все тесты пакета с `-race` — проверка: вывод прогона
