# Изменения

Одна папка на изменение: `changes/YYYY-MM-DD-<имя-по-английски>/`. Шаблон — `_template/`. Одно изменение = одна ветка `change/<имя>` = один PR. Перед ревью исполнитель переносит папку в `archive/` в том же PR.

| Файл | Что в нём | Чего в нём нет |
|---|---|---|
| `proposal.md` | Зачем, что меняется, «Вне изменения:», задетые части, «Найдено по ходу» | Реализации |
| `design.md` | Как сделать, отброшенные варианты, допущения, ссылки на ADR и макеты | Задач |
| `tasks.md` | Проверяемые задачи с чекбоксами по порядку | Обсуждений |
| `specs/<capability>.md` | Сценарии WHEN/THEN: наблюдаемое поведение и инварианты | Кода, псевдокода, тестов |

Статус — первая строка `proposal.md`: `черновик → согласовано → в работе → на ревью`. «Согласовано» означает, что человек поставил на PR метку `go:<исполнитель>`. Слияние видно по PR, отдельного статуса нет.
