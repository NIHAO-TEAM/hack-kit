# Конфиг Playwright для e2e: только Firefox

## Зачем

`e2e/README.md` обещает запуск `npx playwright test` только в Firefox, но конфига нет. Это же — тестовое изменение: PR трогает защищённый путь `e2e/` и после одобрения ревьюером должен слиться **без человека**.

## Что меняется

- Новый `e2e/playwright.config.ts`: один проект `firefox`, `baseURL` из `E2E_BASE_URL`, тесты в `e2e/tests/`, ретраев 0 локально и 1 в CI.
- В `e2e/README.md` команда запуска уточнена под конфиг (`npx playwright test -c playwright.config.ts`).

Вне изменения:
- Сами тесты и CI-задание для e2e.
- Установка зависимостей Playwright (`package.json` для `e2e/`).

## Затронутые части

- backend: нет
- frontend: нет
- контракт `api/openapi.yaml`: нет
- защищённые пути: **да** — `e2e/`. Причина: конфиг живёт рядом с тестами. Сливается без человека после одобрения ревьюером.

## Связанные решения

- ADR: нет
- Макет: не нужен
