# Каркас «Контура удержания»: контракт, схема базы, заглушки модулей

## Зачем

Все изменения этапов 2–6 опираются на один контракт и одну схему. Кейс требует OpenAPI `.yml`/`.json`, Swagger на `/api/v1/docs` и 11 обязательных путей (`docs/case.md`, «Обязательные эндпоинты API»); без них «решение не принимается». Это блокирующее изменение этапа 2 (`!churn-foundation`, `docs/plan.md`): пока оно не слито, остальные изменения этапа не стартуют. После него параллельные изменения заполняют каждый свой модуль и не правят ни контракт, ни миграции.

Решение — ADR-0001, обязательные правки — `docs/decision/03_verdict.md` (правки 2, 5, 9).

## Что меняется

- `api/openapi.yaml` описывает весь API слоёв 1 и 2: 11 обязательных путей кейса, `/metics` как алиас `/metrics`, и наши дополнительные пути (перечень — `design.md`). Существующие `/healthz`, `/version`, `/ping` и заголовок `X-Request-Id` сохраняются без изменений.
- Спека отдаётся сервером по `GET /api/v1/openapi.yml` и `GET /api/v1/openapi.json`; Swagger UI открывается на `GET /api/v1/docs` без входа, файлы UI вшиты в бинарь (без CDN).
- Каждый путь, кроме открытых, отвечает `501 Not Implemented` в формате `application/problem+json`, пока его модуль не реализован.
- Миграции создают таблицы организаторов (`accounts`, `services`, `transactions` — строго как `cases/analizator/001_schema.up.sql`) и служебные таблицы: `model_settings`, `users`, `sessions`, `snapshots`.
- Модули-заглушки `internal/{auth,source,risk,analytics,model}` и `internal/platform/{clock,db,httpx,events}` подключены в `cmd/api`; генератор сервера и `make generate` работают; CI видит дифф, если сгенерированный код не совпадает с контрактом.
- Тестовая обвязка `apitest.New(t)` поднимает API на отдельной базе.

Вне изменения:
- Логика входа, приёма снимка, модели, денег, метрик — у изменений `auth-sessions`, `snapshot-ingest`, этапов 3–4.
- Фронт (`frontend-shell`), Docker и Compose (`compose-stand`).
- Изменение `ci.yml`: проверка `make generate` без диффа уже есть в CI [ГИПОТЕЗА — проверить в задаче 1.4].

## Затронутые части

- backend: `cmd/api`, `internal/platform/*`, заглушки `internal/{auth,source,risk,analytics,model}`, миграции, `Makefile`
- frontend: нет (но контракт задевает фронт: `frontend-shell` генерирует из него типы)
- контракт `api/openapi.yaml`: **да — контракт**
- защищённые пути: **да** — `api/openapi.yaml`. Причина: кейс задаёт пути и поля, по ним жюри тестирует (эксперт: «опенапи спека и эпы сделаны для удобства тестирования нами»)
