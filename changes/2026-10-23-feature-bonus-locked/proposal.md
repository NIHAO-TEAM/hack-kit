# Новый признак «бонус заблокирован» — пример расширяемости

## Зачем

Кейс, требование 7: «Новые признаки и коэффициенты можно добавить без существенной переработки решения, путём минимального редактирования кодовой базы»; приёмка: «способ добавления нового признака». Альтернативщик дебатов: доказать расширяемость реальным PR.

## Что меняется

- Признак `bonus_locked`: бонус на балансе есть, но заблокирован, а средств на 7 дней не хватает (f = 1, иначе 0). Вес по умолчанию **0** — числа модели и питча не меняются; на демо вес включается на экране «Модель».
- Изменение правит **один файл** признака (+ тест) и строку в оракуле; README ссылается на этот PR как на образец.

Вне изменения:
- Изменение весов по умолчанию — нет.
