# GET /ping с параметрами запроса

## Зачем

Тест I (23.10): проверка работы без людей в NIHAO-TEAM — автоназначение по этапу «А» наименее загруженному исполнителю, исполнители на разных аккаунтах, ревьюер valotr0n, слияние агентом. Фиксирует, что параметры запроса не ломают маршрут: проверки доступности иногда добавляют метку времени.

## Что меняется

- Тест: `GET /ping?x=1` и `GET /ping?t=1700000000` → `200`, тело `{"ping":"pong"}`, `Cache-Control: no-store`. Код сервера не меняется.

Вне изменения:
- Код обработчиков, контракт, другие тесты.

## Затронутые части

- backend: `cmd/api` (только новый файл теста `ping_query_test.go`)
- frontend: нет
- контракт `api/openapi.yaml`: нет
- защищённые пути: нет
