# Дизайн: спрятанные заголовки

## Подход

1. Удалить `.sort` из блока `@media (width <= 64em)` в конце `QueueTable.module.css`.
2. Если заголовки скрыты визуально (clip, 1×1) — заменить на `display: none` для `thead` в том же медиазапросе, если это не ломает подпись таблицы для читалки (у таблицы есть `aria-label`); иначе — `tabIndex=-1` у кнопок заголовков на узком экране.
3. Проверить, что axe (`deploy-a11y.yml`) остаётся зелёным.

## Допущения

- [ПРЕДПОЛОЖЕНО] На узком экране сортировка доступна только через `SortControl` — этого достаточно и для клавиатуры, и для читалки.

## Риски

- `display: none` у `thead` убирает заголовки столбцов для читалки в строках-карточках; если в строках-карточках есть свои подписи полей — допустимо, иначе — вариант с `tabIndex=-1`.
