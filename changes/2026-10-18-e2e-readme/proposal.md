# Как запускать e2e: e2e/README.md

## Зачем

Перед первым e2e-сценарием команде нужен один файл с правилами: чем запускать, на каком стенде, как сбрасывать стенд. Это же — тестовое изменение для проверки метки `protected`: `e2e/` — защищённый путь, такой PR после одобрения сливает человек.

## Что меняется

- Новый файл `e2e/README.md`: Playwright, только Firefox, переменные `E2E_BASE_URL` и `E2E_DEMO_TOKEN`, сброс стенда перед прогоном, где лежит демо-сценарий (`docs/demo-script.md`).

Вне изменения:
- Сами тесты и конфиг Playwright.
- CI-задание для e2e.

## Затронутые части

- backend: нет
- frontend: нет
- контракт `api/openapi.yaml`: нет
- защищённые пути: **да** — `e2e/README.md`. Причина: правила e2e живут рядом с тестами. Слияние — только человеком.

## Связанные решения

- ADR: нет
- Макет: не нужен
